# Interface utilisateur

Chaque famille d'E/S possède une présentation uniforme.

Exemple :

AO1 AO2 AO3 AO4
AI1 AI2 AI3 AI4
RO1 RO2 RO3 RO4
DO1 DO2 DO3 DO4
DI1 DI2 DI3 DI4
R1  R2  R3  R4

Les simulateurs de résistance utilisent :
- sélection de plage
- réglage grossier
- réglage fin
- affichage de la résistance

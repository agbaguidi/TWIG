# Vision du projet

## Objectif
Concevoir un banc universel d'instrumentation destiné au développement embarqué et industriel.

## Philosophie
- Phase 1 : fonctionnement principalement matériel, sans MCU.
- Phase 2 : ajout d'une intelligence (MCU) sans remettre en cause l'architecture.
- Conception robuste, réparable et évolutive.
